// PRIORITY ISSUES
P1

No dark mode

SurfaceDark, SurfacePanelDark, PrimaryDark tokens exist but nothing applies them. No AppThemeBinding anywhere. Every dark-OS-theme user gets a cream flood. The debug panel (#1A1D21) and confidence bar lose context entirely.

FIX: Add AppThemeBinding to App.xaml resources. Light → current values; Dark → SurfaceDark/PrimaryDark + tinted panel variants.
P1

No visible focus or disabled states

Focus tokens exist but only Button uses them. Entry, Picker, mic button have no focus ring. Disabled pickers show zero visual change — no opacity, no desaturation. The user clicks and gets nothing.

FIX: Add Disabled visual state (Opacity 0.5) to Picker/Entry. Apply FocusRing to all interactive controls.
P2

Info palette = Success palette (semantic collapse)

Info tokens are byte-identical to Success. If anything uses Info for neutral information, users will misread "green = success."

FIX: Give Info a distinct muted teal or steel blue. Info should mean "information," not "success."
P2

Confidence bar red/green — colorblind fail

Progress bar toggles #2D8C4F/#C04040. Deuteranopia and protanopia (~8% of men) see identical muddy brown.

FIX: Add shape/pulse distinction or switch to blue/red. Text label below already provides fallback.
P2

122 XAML compilation warnings

All RecitationPage bindings use runtime reflection. Bindings fire on every audio chunk — real performance drag.

FIX: Add x:DataType to all pages and DataTemplates. One XML attribute per page.
P2

Reset has no undo

Clicking Reset or pressing Escape instantly wipes the session. Flagged in June, still unresolved.

FIX: Show a 5-second toast with undo. Require double-press or Shift+Esc for keyboard reset.
